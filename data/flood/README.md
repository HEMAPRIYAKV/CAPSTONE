\# Chennai Flood Hazard Dataset



The flood exposure module uses:



`chennai\_flood\_hazard.kml`



The KML contains Chennai flood-hazard polygons classified into:



\- Very Low

\- Low

\- Moderate

\- High

\- Very High



The dataset is approximately 38 MB and is intentionally not stored in the normal Git repository.



Place the KML file at:



data/flood/chennai\_flood\_hazard.kml



before running the flood exposure and risk-aware routing modules.



\## Expected file



chennai\_flood\_hazard.kml



\## Usage



The backend loads this dataset through:



backend/flood\_exposure.py
